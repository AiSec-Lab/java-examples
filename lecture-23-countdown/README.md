# Lecture 23 countdown animation

Interactive source-level trace for `countDown(3)`. It shows every argument evaluation, method entry, base-case check, print, recursive call, resume, and return. The call frames retain their own parameter values while a smaller call runs.

Run `python3 build_trace.py` after changing the Java example, then run `python3 verify.py`. Open `index.html#countdown` locally or use the published page:

https://aisec-lab.github.io/java-examples/lecture-23-countdown/#countdown
