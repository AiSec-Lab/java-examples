# CPS 151 Java execution animations

Interactive browser animations for Exercises 2–5.

- `exercise-02/`: methods, references, increments, and constructors
- `exercise-03/`: inheritance, constructor chaining, composition, and overriding
- `exercise-04/`: pre/post increments, constructors, composition, and overriding

The site is deployed automatically to GitHub Pages when `main` changes.

- `exercise-05-recursion/`: puzzle, factorial, array sum, and string reverse. Direct links: `#puzzle`, `#factorial`, `#array-sum`, `#reverse`.

- `lecture-25-recursion-analysis/`: six complete recursion-analysis traces, with call/depth/cache metrics and call history.

- `lecture-26-elementary-sorting/`: six sorting traces with step-by-step array changes, analysis, operation counts, and runnable Java examples.

- `lecture-27-efficient-sorting/`: seven merge-sort, quicksort, comparison-input, and pivot-strategy animations with live analysis.
